# Jenaida Homes

A luxury storefront website for curtains, pillows, shears, and home textiles.

## Run locally
Open `index.html` in a browser.

## Features
- Luxury themed storefront
- Product pricing section
- Gallery layout using local SVG visuals
- WhatsApp order buttons
- Mobile responsive design
